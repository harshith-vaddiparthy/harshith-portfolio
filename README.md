## ✨ Features

- **Interactive Agent Architecture Lab**: A live simulator showcasing enterprise multi-agent coordination, zero-trust DOM boundaries, and Model Context Protocol (MCP) server execution.
- **Engineering Blog & Technical Dives**: Three deep-dive articles authored with evidence classification (`Production Benchmark`, `Security Exploit & Fix`, `Architectural Blueprint`), runnable code snippets, ASCII architecture diagrams, and published trade-offs ledgers.
- **Leadership & Track Record**: Concentric double-bezel cards filtering roles across Executive & CTO, Instruction & Training, Press & Council, Growth, and Angel Investments (e.g. Beehiiv Series B).
- **Outskill AI Education Showcase**: Curriculum and telemetry covering 10,000+ engineers trained across Claude Mastery, Google AI Studio, n8n, Dify, and Vibe Coding.
- **Interactive AI Twin Console**: Interactive terminal allowing visitors to query Harshith's engineering persona in real time.
- **Design System**: Double-Bezel hardware architecture, bespoke radial mesh lighting, and accessible responsive layouts adhering to modern anti-slop frontend guidelines.

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.com) (`curl -fsSL https://bun.sh | bash`) or Node.js 20+

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/harshith-vaddiparthy/harshith-portfolio.git
cd harshith-portfolio

# Install dependencies
bun install

# Start development server
bun run dev

# Build production bundle
bun run build

# Preview production build locally
bun run preview
```
