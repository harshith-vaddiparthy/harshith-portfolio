# Failure modes

Consult this table when a draft, a published post, or a review round is going wrong. It is a reactive lookup, not part of the sequential workflow.

| Symptom                                                    | Cause                                           | Fix                                                                         |
| ---------------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------- |
| Reads like a press release                                 | Marketing register, no first person             | Restore the engineer's voice; add what was hard and what was cut            |
| Comment thread attacks the benchmark                       | Methodology missing or unfair tuning            | Publish the full setup; re-run with both sides tuned or label it indicative |
| Post mixes a tutorial into an incident story               | No pattern chosen                               | Pick one pattern; split the rest into a separate artefact                   |
| Nobody finishes it                                         | Opening runs long before any substance          | Cut the preamble; put the surprise or the number on the first screen        |
| An engineer disputes it after publishing                   | No technical review                             | Add the review step; correct in public with a dated note                    |
| Every claim needs a caveat                                 | Topic has no evidence behind it                 | Downgrade to a marked opinion post, or go measure                           |
| The draft is accurate and dull                             | Wrote from mastery, not from the struggle       | Refocus on the part that surprised the author                               |
| The product post reads as an ad                            | Product written as the subject, not the setting | Lead with the engineering problem; name what you sell once, plainly         |
| Reviewer returns line edits, not the fact check you needed | Draft sent with no reviewer brief               | Say what you want checked before sending                                    |
